🌾 Nông Trại Khai Mở

Dữ liệu nhân vật cần một thư mục data trên máy bạn.

Hướng dẫn:
1. Trong thư mục Downloads, tạo folder tên data (hoặc chọn folder bất kỳ).
2. Bấm nút bên dưới và chọn đúng folder data đó.
3. Game sẽ tạo thư mục con cho từng nhân vật bên trong.

Trình duyệt không cho tự ghi vào Downloads — bạn phải chọn folder một lần (Chrome/Edge khuyến nghị).
